# Wheel of Fortune: Logic Circuits Project

A digital-logic simulation created in Proteus for the third-semester Logic Circuits course at Iran University of Science and Technology, taught by Dr. Amir Mahdi Hosseini Monazzah.

**Team:** Farzan Rahmani and Mohammad Osoolian.

## Project Concept

The selected assignment is a wheel-of-fortune circuit. Its specification calls for a trigger input, generation of three random values, display on three seven-segment indicators, a win/loss result, and an automatic reset before the next input. See the original statement and team report for the implementation details and timing behavior.

## Open and Simulate

1. Install a compatible version of Proteus with the digital simulation components required by the project.
2. Open `Gardanande_Shans.pdsprj` and inspect the schematic, input controls, display components, and timing sources.
3. Read the report and assignment statement to identify the expected control sequence.
4. Start the simulation, apply the trigger input, and observe the displayed values, result, and reset cycle.

The repository contains the Proteus design rather than a command-line application. Component-library availability and project compatibility depend on the installed Proteus version; no specific version or hardware build procedure is supplied.
